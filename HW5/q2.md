## B

This design assumes the OS serializes page table and reference count updates

```text
fork(parent):
    child = allocate process and reserve space for its page table
    if allocation fails:
        return error

    for each mapped virtual page v in parent's page table:
        # Give the child its own PTE pointing to the same physical page.
        parent.pte[v].writable = false
        parent.pte[v].cow = true
        child.pte[v] = copy of parent.pte[v]
        parent.pte[v].phys_page.refcount++

    flush parent's TLB   # Cached entries might still allow writes.
    make child runnable
    return child


page_fault(proc, addr, access_type):
    v = virtual page containing addr
    pte = proc.pte[v]

    if access_type != WRITE or pte is missing or pte.cow == false:
        terminate proc for invalid access
        return

    old_page = pte.phys_page

    if old_page.refcount == 1:
        # This is the only mapping left, so reuse the page.
        pte.writable = true
        pte.cow = false
        flush proc's TLB entry for v
    else:
        new_page = allocate physical page
        if allocation fails:
            terminate proc for running out of memory
            return

        copy contents of old_page into new_page
        pte.phys_page = new_page
        pte.writable = true
        pte.cow = false
        new_page.refcount = 1
        flush proc's TLB entry for v
        old_page.refcount--

    retry the instruction


exit(proc):
    stop proc from running

    for each mapped virtual page v in proc's page table:
        phys_page = proc.pte[v].phys_page
        remove proc.pte[v]
        flush proc's TLB entry for v

        phys_page.refcount--
        if phys_page.refcount == 0:
            free phys_page

    free proc's page table
```

## C

`A0` and `B0` are the original physical pages, `A1` is the copy created for the child. The num in parthenes is ref count after each step.

| Step | Parent P maps | Child C maps | What happens |
|---|---|---|---|
| 1. P owns A and B | `A0` (1), `B0` (1) | — | P can write to both pages |
| 2. P calls `fork()` | `A0` (2), `B0` (2) | `A0` (2), `B0` (2) | Both processes share both physical pages, All four mappings are read only and marked COW. |
| 3. C writes to A | `A0` (1), `B0` (2) | `A1` (1), `B0` (2) | C faults, The OS copies `A0` to `A1`, makes C's mapping writable, and retries the write. |
| 4. P writes to A | `A0` (1), `B0` (2) | `A1` (1), `B0` (2) | P faults because its mapping is still marked COW, Since `A0` has only one reference, the os makes P mapping writable in place and retries the write. |
| 5. C exits | `A0` (1), `B0` (1) | — | `A1` is freed, `B0` stays allocated because P still maps it. |
| 6. P exits | — | — | `A0` and `B0` both reach zero references and are freed. |

The os makes one physcial copy when C first writes to A. Neither process writes to B so they share it until C exits.
